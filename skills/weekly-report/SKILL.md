# 周报生成

## 步骤

1. 调 `commit_activity` 和 `pull_health`，窗口设为 7 天。
2. 如果是 Java 仓库，补调 `repo_structure` 拿测试比例做健康度参考。
3. 按下面结构输出，控制在一屏内：

```
## 本周概览
（两句话：提交多少、合并多少、有没有异常）

## 数据
（三到五个数字，只挑能说明问题的）

## 需要关注
（一到两条，没有就写"无"）

## 下周建议
（一到两条，要具体到动作）
```

## 注意

- **周报不是指标罗列。** 数字最多五个，多了没人看。
- 窗口不足 7 天时要说明覆盖率，不要用短窗口的数推周均。
- 没有异常就直说没有，不要为了凑内容硬找问题。
- 不要写"团队整体表现良好"这类空话，要么给数字，要么不写。
